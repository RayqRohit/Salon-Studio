# Salon Studio

A modern, high-performance website and admin panel for a luxury salon & beauty studio.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database & Auth:** Supabase (PostgreSQL)
- **ORM:** Prisma
- **Deployment:** Vercel

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
